# SAA-Notes

AWS Solutions Architect Associate (SAA) 考試學習筆記專案

2025-10-15

## 📚 專案概述

這是一個系統性的 AWS SAA 考試準備專案，透過三種不同類型的學習材料來建構完整的知識體系：

- **AI 問答筆記**：透過與 AI 助手對話產生的系統性學習材料
- **題目解析**：Udemy 課程隨堂驗測的詳細題解
- **模擬考練習**：Dojo 平台模擬考試的實戰分析

## 🎯 目錄說明

### 📖 Notes (AI 問答筆記)
- **目的**：透過與 AI 助手的對話互動建構系統性學習材料
- **特色**：完整的 AWS SAA 知識體系，AI 輔助概念解釋
- **範圍**：18 個主要章節，涵蓋考試完整內容
- **格式**：`{序號}-{主題名稱}.md`

### 🔍 Questions (題目解析)
- **目的**：Udemy 課程隨堂驗測的詳細題解
- **特色**：一題一篇，專注於概念澄清和知識點補強
- **來源**：Udemy 課程 + AI 分析
- **格式**：`{序號}-{直述句標題}.md`

### 🥋 Dojo (模擬考練習)
- **目的**：Dojo 平台模擬考試的實戰分析
- **特色**：實戰導向，綜合性場景和高難度挑戰
- **內容**：可能單題或多題組合分析
- **格式**：`{序號}-{核心主題}.md`

## 🛠️ 專用工具

### Prompts 系統
專案包含四個專用的 prompt 檔案，用於不同類型內容的標準化管理：

- **notes.prompt.md**：AI 問答筆記的檔名和標題管理
- **question.prompt.md**：Udemy 題解的格式標準化
- **dojo.prompt.md**：Dojo 模擬考題解的內容管理
- **cspell.prompt.md**：拼字檢查錯誤的批量處理

## 📝 內容特色

- **語言**：繁體中文 (zh-TW)
- **術語處理**：AWS 服務名稱保持英文，技術術語提供中文翻譯
- **結構化**：使用表格、清單、引用塊組織複雜概念
- **考試導向**：每篇筆記都針對 SAA 考試重點設計
- **漸進式難度**：基礎理論 → 概念驗證 → 實戰模擬

## 🚀 使用方式

1. **系統性學習**：從 `notes/` 目錄按序號順序學習基礎理論
2. **概念驗證**：使用 `questions/` 目錄的題解加強理解
3. **實戰練習**：透過 `dojo/` 目錄進行模擬考試練習
4. **工具輔助**：使用對應的 prompt 檔案進行內容管理和格式標準化
