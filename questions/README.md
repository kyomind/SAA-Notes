# Questions 目錄說明

2025-10-15

## 📝 目錄用途

這個目錄專門收錄 **AWS SAA 考試題解和知識點澄清**，內容來源是將 **Udemy 課程中的隨堂驗測題目交給 AI 分析**，產生的詳細題目解析。

## 🎯 文件性質

### 內容來源
- **題目來源**：Udemy AWS SAA 課程的隨堂驗測
- **解析方式**：AI 輔助分析題目並生成詳細解釋
- **格式標準**：每一篇文件對應一題的完整解析

### 內容特色
- **考試導向**：專門解決 SAA 考試中的疑難問題
- **概念澄清**：釐清容易混淆的技術概念
- **實例說明**：用具體場景幫助理解抽象概念
- **對比分析**：比較相似服務或功能的差異

### 文件結構
每個題解文件包含：
- **核心概念**：問題的本質和關鍵知識點
- **使用場景**：實際應用情境和範例
- **服務比較**：相關 AWS 服務的差異對照
- **考試重點**：應試時的判斷依據和記憶要點

## 📂 檔案命名規範

```
{序號}-{直述句標題}.md
```

**範例**：
- `01-SNI 支援單一 listener 綁定多個 SSL 憑證.md`
- `02-ALB 與 NLB 的 SNI 支援差異.md`

### 標題規則
- 使用**直述句**描述核心概念
- 避免「正確答案」、「題解」等前綴詞
- 重點放在技術特性或應用場景

## 🔗 與主筆記的關係

- **主筆記** (`/`)：系統性學習材料，按章節組織
- **Questions** (`/questions/`)：Udemy 隨堂驗測的 AI 題解，一題一篇

Questions 目錄是主筆記的**補充和深化**，透過具體考題來驗證和加強對概念的理解。每篇題解都是針對單一題目的深度分析，幫助釐清考試中的關鍵判斷點。

## 💡 使用建議

1. **考前複習**：快速查找特定概念的考試重點
2. **疑難解答**：當對某個知識點有疑問時，查看相關題解
3. **概念對比**：了解相似服務或功能的區別
4. **實例理解**：透過具體場景加深概念記憶

---

> **提醒**：這些題解都是為了 SAA 考試準備，重點在於理解概念和應試技巧，不是完整的服務使用手冊。
