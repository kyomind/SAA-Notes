# Notes 目錄說明

2025-10-15

## 📚 目錄用途

這個目錄專門收錄 **AWS SAA 考試的 AI 問答筆記**，透過與 AI 助手的對話互動來建構系統性的學習材料。

## 🎯 文件性質

### 內容來源

- **筆記來源**：與 AI 助手的問答對話記錄
- **學習方式**：透過提問、討論、澄清來深化理解
- **內容特色**：結合理論知識與實務應用的綜合性筆記

### 內容特色

- **系統性學習**：按章節編號組織，涵蓋 SAA 考試完整知識體系
- **AI 輔助理解**：透過與 AI 的對話來解釋複雜概念
- **實務導向**：結合考試重點與實際應用場景
- **漸進式建構**：從基礎概念逐步建立完整的知識架構

### 文件結構

每個筆記文件包含：

- **核心概念**：主要的 AWS 服務或技術知識點
- **詳細說明**：透過 AI 問答產生的深度解釋
- **實務應用**：實際使用場景和最佳實務
- **考試重點**：SAA 考試中的關鍵判斷點
- **相關服務**：與其他 AWS 服務的整合和比較

## 📂 檔案命名規範

```markdown
{序號}-{主題名稱}.md
```

**範例**：

- `01-Region and IAM.md`
- `03-AWS EC2 與 Spot Instances.md`
- `18-AWS Lambda 與 DynamoDB.md`

### 編號規則

- 使用兩位數序號（`01-`、`02-` 等）
- 按照學習進度和邏輯順序排列
- 涵蓋 SAA 考試的完整知識範圍

### 標題格式

- 中英文混合使用
- AWS 服務名稱保持英文原文
- 使用清晰描述性的標題

## 🔗 與其他目錄的關係

- **Notes** (`/notes/`)：AI 問答筆記，系統性學習材料
- **Questions** (`/questions/`)：Udemy 隨堂驗測的 AI 題解
- **Dojo** (`/dojo/`)：Dojo 模擬考試的實戰練習

Notes 目錄是整個學習體系的**核心基礎**，提供完整的理論知識架構。透過與 AI 的問答對話，建立對 AWS 服務的深度理解，為後續的題目練習和模擬考試打下堅實的基礎。

## 📝 學習建議

1. **循序漸進**：按照檔案編號順序學習
2. **主動提問**：利用 AI 助手澄清疑問
3. **實務結合**：理解概念的同時思考實際應用
4. **定期複習**：回顧之前的筆記內容
5. **交叉驗證**：結合 questions 和 dojo 目錄的題目練習
