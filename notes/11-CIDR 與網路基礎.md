# 11-CIDR 與網路基礎

2025-10-10

## CIDR 核心概念

**CIDR (Classless Inter-Domain Routing)** 是一種 IP 位址表示法，用於定義網路範圍。

### 格式
```
IP位址/前綴長度
例如：192.168.1.0/24
```

### 前綴長度的意義

**前綴長度 = IP 位址中「固定不變」的位元數**

- IP 位址總共 32 位元
- `/24` = 前 24 位元固定，後 8 位元可變
- 後 8 位元可變 = 2^8 = **256 個 IP**

### 快速計算公式

```
可用 IP 數 = 2^(32 - 前綴長度)
```

| CIDR | 計算 | 可用 IP 數 | 典型用途 |
|------|------|-----------|----------|
| /32 | 2^0 | 1 | 單一主機 |
| /28 | 2^4 | 16 | 最小 Subnet |
| /24 | 2^8 | 256 | 小型網路 |
| /16 | 2^16 | 65,536 | VPC 預設 |
| /8 | 2^24 | 16,777,216 | 超大型網路 |

> **記憶技巧**：數字越大 = 範圍越小 = IP 越少

---

## 私有 IP 範圍 (RFC 1918)

**內網 IP 只有這三種開頭**：

| CIDR | IP 範圍 | 總 IP 數 | 使用場景 |
|------|---------|----------|----------|
| 10.0.0.0/8 | 10.0.0.0 - 10.255.255.255 | 16,777,216 | **AWS VPC 預設** |
| 172.16.0.0/12 | 172.16.0.0 - 172.31.255.255 | 1,048,576 | 中型企業網路 |
| 192.168.0.0/16 | 192.168.0.0 - 192.168.255.255 | 65,536 | 家用路由器 |

### 私有 IP 特性

- ✅ **不能直接連上網際網路**
- ✅ 必須透過 **NAT Gateway** 才能對外連線
- ✅ 全世界任何人都可在內網使用（不會衝突）
- ✅ 其他開頭的 IP = 公網 IP

> **SAA 陷阱**：`172.32.x.x` 不是私有 IP！只有 `172.16.x.x` 到 `172.31.x.x` 才是。

## AWS VPC 網路規劃

### VPC CIDR 限制

| 項目 | 限制 |
|------|------|
| 最大 | /16（65,536 個 IP）|
| 最小 | /28（16 個 IP）|
| 必須使用 | 私有 IP 範圍 |

> **考試重點**：VPC CIDR 必須在 `/16` 到 `/28` 之間

### 為什麼最小是 /28？

- /28 = 16 個 IP
- AWS 保留 5 個 IP
- **實際可用 = 11 個 IP**
- 這是 AWS 認為「能正常運作的最小網路」

---

## AWS Subnet 保留 IP

**每個 Subnet 的前 4 個 + 最後 1 個 IP 被 AWS 保留**

### 實際範例：10.0.1.0/28

| IP 位址 | 用途 |
|---------|------|
| 10.0.1.0 | 網路位址（保留）|
| 10.0.1.1 | VPC Router（保留）|
| 10.0.1.2 | DNS Server（保留）|
| 10.0.1.3 | AWS 未來使用（保留）|
| **10.0.1.4 - 10.0.1.14** | **可用 IP（11 個）** |
| 10.0.1.15 | 廣播位址（保留）|

> **計算公式**：實際可用 IP = 總數 - 5

## AWS VPC 架構範例

### 典型三層架構

```
VPC: 10.0.0.0/16                    # 整個內網（65,536 IP）
│
├─ Public Subnet:  10.0.1.0/24      # 放 Load Balancer（256 IP）
│  └─ 對外連線，有 Internet Gateway
│
├─ Private Subnet: 10.0.2.0/24      # 放 EC2 應用伺服器（256 IP）
│  └─ 透過 NAT Gateway 對外
│
└─ DB Subnet:      10.0.3.0/24      # 放 RDS 資料庫（256 IP）
   └─ 完全隔離，不對外
```

### Multi-AZ 高可用架構

```
VPC: 10.0.0.0/16
│
├─ AZ-A
│  ├─ Public:  10.0.1.0/24
│  ├─ Private: 10.0.2.0/24
│  └─ DB:      10.0.3.0/24
│
└─ AZ-B
   ├─ Public:  10.0.11.0/24
   ├─ Private: 10.0.12.0/24
   └─ DB:      10.0.13.0/24
```

## SAA 考試重點整理

### 1. CIDR 基礎判斷

- **數字越大 = 範圍越小**
- `/32` = 單一 IP（Security Group 限制特定主機）
- `/0` = 所有 IP（0.0.0.0/0 = 整個網際網路）

### 2. VPC 規劃考點

✅ VPC CIDR 必須在 `/16` 到 `/28`
✅ 每個 Subnet 實際可用 IP = 總數 - 5
✅ VPC Peering 時，兩邊 CIDR 不能重疊
✅ 一個 VPC 最多可有 5 個 CIDR 區塊

### 3. 私有 IP 識別

| IP 開頭 | 類型 |
|---------|------|
| 10.x.x.x | 私有 ✅ |
| 172.16.x.x - 172.31.x.x | 私有 ✅ |
| 192.168.x.x | 私有 ✅ |
| 172.32.x.x | 公網 ❌ |
| 其他 | 公網 ❌ |

### 4. Security Group CIDR 用法

```
允許特定 IP:     203.0.113.5/32
允許整個 Subnet:  10.0.1.0/24
允許整個 VPC:     10.0.0.0/16
允許全網際網路:   0.0.0.0/0
```

> **考試陷阱**：題目問「最安全的設定」，答案通常是 `/32`（限制單一 IP）

### 5. NAT Gateway 與對外連線

- **私有 IP 不能直接上網**
- Private Subnet 透過 **NAT Gateway** 對外
- Public Subnet 透過 **Internet Gateway** 對外

## 快速記憶卡

### CIDR 常用值

| CIDR | IP 數 | 記憶方式 |
|------|-------|----------|
| /32 | 1 | 3-2 = 單一 |
| /24 | 256 | 24 小時 → 256 |
| /16 | 65K | VPC 預設 |
| /8 | 16M | 10.0.0.0/8 |

### 考試速判表

| 題目關鍵字 | 可能答案 |
|-----------|---------|
| 「最小權限」、「特定主機」 | /32 |
| 「整個網際網路」、「所有來源」 | 0.0.0.0/0 |
| 「VPC 預設大小」 | /16 |
| 「Subnet 最小」 | /28 |
| 「Private IP」 | 10.x / 172.16-31.x / 192.168.x |

## 補充：Subnet 切割實戰

### 題目：如何將 10.0.0.0/16 切成 4 個相等 Subnet？

**解答**：
```
10.0.0.0/16 → 需要 4 個 Subnet → 2^2 = 4
16 + 2 = 18 → 每個 Subnet 用 /18

結果：
10.0.0.0/18    (10.0.0.0   - 10.0.63.255)
10.0.64.0/18   (10.0.64.0  - 10.0.127.255)
10.0.128.0/18  (10.0.128.0 - 10.0.191.255)
10.0.192.0/18  (10.0.192.0 - 10.0.255.255)
```

> **考試技巧**：不需要實際計算，只要知道「/16 可以切成多個 /24」這種大小關係即可
