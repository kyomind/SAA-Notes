# 14-S3 核心功能與應用

2025-10-11

---

### ✅ 重點理解原則

> 在 SAA 考試中，S3 不只是儲存服務，更是許多自動化與安全場景的核心。理解各功能的**使用場景**與**差異**，比記規格更重要。

---

## 📦 Amazon S3 基礎服務與擴充功能

### 🔍 S3 Storage Lens

**用途**：提供帳號下所有 S3 bucket 的**儲存使用統計**與**趨勢視覺化分析**。

**重點場景**：

* 想要整體了解 S3 使用趨勢
* 輕鬆找出花費最多的 bucket
* 優化儲存策略

**常考重點**：

> 📌 若題目問你「如何分析所有 bucket 的使用趨勢與成本優化」，選 **S3 Storage Lens**

**與 S3 Analytics 差異**：

| 功能   | S3 Storage Lens | S3 Storage Class Analysis (S3 Analytics) |
| ---- | --------------- | ---------------------------------------- |
| 範圍   | 跨 bucket 全局分析   | 針對單一 bucket 或 prefix                     |
| 用途   | 管理/成本優化         | 建議轉換為 IA 類別                              |
| 結果形式 | 儀表板 + 匯出報告      | 匯出報表 (CSV)                               |

---

### 📜 S3 Server Access Logs

**用途**：記錄誰在什麼時間點對 S3 資源發出什麼操作（如 GET、PUT）

**常見用途**：

* 安全稽核與合規追蹤
* 疑難排解：調查誰存取或刪除了資料

**考點提醒**：

> 📌 若題目提到「需要追蹤誰什麼時間存取了檔案」，答案是 **S3 Access Logs**（非 CloudTrail）

---

### 🔐 Pre-Signed URLs

**用途**：產生一個臨時有效的 URL，讓使用者可於特定時間內存取 S3 檔案。

**使用情境**：

* 後端系統產生圖片或報表連結給前端用戶下載
* 用戶無需 IAM 權限

**考試常見誤解**：

> ✅ 有 Pre-Signed URL 的人，只要在有效時間內都能存取，不管是不是原使用者

---

### 🎯 S3 Access Point

**用途**：為同一個 bucket 建立多個端點，每個端點可套用不同的 IAM policy 與網路控制（VPC endpoint）。

**實用場景**：

* 多個應用或部門共同使用一個 bucket，但需要不同的權限控制
* 提高 VPC 安全性與資料分隔

**考試關鍵字**：

> 📌 題目提到「不同應用或 VPC 要安全存取同一 bucket」，選 **S3 Access Point**

---

### ⚙️ S3 事件觸發 Lambda（Event Notification）

**用途**：當某個事件發生時（如物件上傳），自動觸發一個 Lambda 函數。

**典型場景**：

* 圖片上傳後自動轉檔或壓縮
* 上傳檔案後更新資料庫 metadata

**考試提示**：

> 📌 題目問你「物件上傳後如何自動處理」，選 **S3 事件 + Lambda**

---

## 🔐 S3 Object Lock 與版本控制

### 1️⃣ Legal Hold vs Governance Mode

| 特性   | Legal Hold  | Governance Mode |
| ---- | ----------- | --------------- |
| 鎖定條件 | 可隨時開關       | 有保留時間限制         |
| 權限需求 | 一般 IAM 即可移除 | 需要特殊權限才能移除      |
| 使用場景 | 符合法律要求的調查保護 | 資料保護但允許例外處理     |

**補充觀念**：

* 兩者皆屬於 Object Lock 的應用
* 必須搭配版本控制（Versioning）啟用

---

## 🧪 題目判斷技巧快速整理

| 考題需求             | 選用服務                                       |
| ---------------- | ------------------------------------------ |
| 分析所有 S3 儲存趨勢     | S3 Storage Lens                            |
| 單一 bucket 存取模式分析 | S3 Analytics                               |
| 臨時授權下載檔案         | Pre-Signed URL                             |
| 記錄誰存取了 bucket    | S3 Access Logs                             |
| 上傳後自動執行程式        | S3 + Lambda                                |
| 多部門存取共用資料        | S3 Access Point                            |
| 防止誤刪除物件          | Object Lock (Governance Mode / Legal Hold) |

---

## 🧩 延伸補充（進階學習）

* **Object Lock 還有另一種模式：Compliance Mode**，完全無法刪除，即使是 root 使用者。
* 若你在考試遇到需要防止任何人改動的場景，應選 **Compliance Mode**。

---

> 🎯 記住：S3 本身功能很多，但考試重點是「能不能選對工具解決場景問題」。熟悉常見用途與搭配方式，你就比很多人領先一步。
